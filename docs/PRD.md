# daaspro 产品需求文档

> 文档用途：描述 daaspro 面向用户的业务功能、操作方式、业务规则和主要业务流程。
> 产品定位与业务边界参考：[重构需求共识](./重构需求共识.md)。

---

## 1. 产品定位

daaspro 是面向数据分析师和数据开发工程师的数据工作平台，围绕“接入数据、管理数据、分析数据、加工数据、发布数据、消费数据”提供连续的业务能力。

一个团队在平台中拥有独立的工作区。工作区成员可以接入数据库、导入文件、编写 SQL、配置数据同步任务、编排工作流、制作图表与仪表盘，并将数据或 Python 模型以受控 API 的方式提供给其他系统。

平台采用简化的团队协作方式：以工作区隔离数据和资源，工作区内设置管理员与成员两类角色。资源默认在工作区内共享，不提供复杂的按钮级权限矩阵。

---

## 2. 用户角色

### 2.1 工作区管理员

- 创建并维护工作区。
- 管理工作区成员，创建成员账号、调整成员角色、停用成员账号。
- 管理工作区内的数据源、数据集、SQL 脚本、同步任务、工作流、API、应用、图表和仪表盘。
- 管理工作区 Python 执行资源配额。
- 查看工作区内资源和任务运行信息。

### 2.2 工作区成员

- 使用工作区内可见的数据源和数据集。
- 创建、编辑和运行 SQL 脚本、数据同步任务和工作流。
- 创建数据 API、调用应用、图表和仪表盘。
- 使用 Notebook 和 Python 模型能力处理工作区数据。
- 查看工作区内任务和资源的运行状态。

### 2.3 外部 API 调用方

外部系统不是平台登录用户。工作区成员为外部系统创建调用应用，并向应用授权指定 API。外部系统使用应用凭证调用被授权的数据 API 或 Python 模型服务。

### 2.4 平台运维人员

负责平台实例和基础服务运行维护。平台运维身份不作为工作区内的数据业务角色，不默认获得工作区数据访问权。

## 3. 信息架构

### 3.1 工作区导航

- **工作台**：工作区概览、常用入口、最近访问资源和近期运行情况。
- **数据源**：数据源列表、连接配置、连通测试、库表浏览。
- **数据管理**：数据源目录、表结构、文件导入、数据集列表和数据预览。
- **SQL 分析**：SQL 编辑器、脚本列表、执行结果和导出。
- **数据同步**：同步任务列表、任务配置、运行记录和调度设置。
- **工作流**：流程列表、DAG 编辑、运行实例和调度设置。
- **数据服务**：API 发布、调用应用、API 授权和调用记录。
- **可视化分析**：图表制作、图表管理、仪表盘管理。
- **Python 开发**：Notebook、程序模型、共享脚本、运行记录和模型 API。
- **工作区管理**：成员管理、工作区信息和 Python 资源配额。

### 3.2 工作台

工作台展示当前工作区名称、当前用户和角色，并提供以下工作入口：

- 新建数据源、上传数据、打开 SQL 分析。
- 最近访问的数据集、脚本、图表和仪表盘。
- 最近执行的同步任务、工作流和 Python 任务及其状态。
- 常用资源收藏或快捷入口。
- 当前工作区成员可见的资源统计和待处理运行状态。

用户首次进入工作区时，工作台突出显示“接入数据”操作；已有数据时，显示最近使用资源和继续处理入口。

## 4. 工作区与成员管理

### 4.1 创建工作区

用户输入团队名称、管理员用户名和密码后创建工作区。创建完成后，创建者成为工作区管理员并进入工作台。工作区拥有独立的数据空间和资源目录。

### 4.2 登录与退出

用户使用平台账号登录工作区。登录成功后进入工作台；退出后结束当前登录会话。账号被管理员停用后，用户不能继续进入工作区。

### 4.3 成员列表

成员管理页面展示用户名、显示名称、角色、账号状态和加入时间。管理员可以按用户名或显示名称搜索成员，并按角色或状态筛选。

### 4.4 创建成员

管理员填写用户名、显示名称、初始密码和角色，创建成员账号。成员首次登录后可修改自己的密码和显示名称。用户名在平台范围内唯一。

### 4.5 修改成员与停用

管理员可修改成员显示名称和角色，也可停用成员。管理员不能停用当前自己的账号。停用账号后，账号不再允许登录；其创建的工作区资源保留并继续归工作区管理。

### 4.6 工作区资源共享

工作区内的数据源、数据集、SQL 脚本、同步任务、工作流、API、图表、仪表盘和 Python 模型默认为工作区共享资源。创建者信息用于记录来源和展示，不形成资源私有隔离。删除或停用资源时，由系统检查引用关系并提示对下游资源的影响。

## 5. 数据源管理

### 5.1 数据源类型

工作区包含平台内置 PostgreSQL 数据源，并可添加外部数据库连接。外部连接类型包括 PostgreSQL、MySQL、Oracle、SQL Server、Hive 和 Doris；每种连接可使用的浏览、查询、同步读取或写入能力由连接类型支持情况决定。

文件不是数据库连接，用户通过数据管理中的文件导入流程将文件转换为平台数据集。

### 5.2 数据源列表

数据源列表展示名称、类型、连接地址摘要、默认 schema/数据库、内置标识、连接状态和最近检测时间。列表提供新建、编辑、测试连接、浏览表结构和删除操作。

内置数据源标记为平台数据区，不允许删除或修改其租户归属。普通列表不展示连接密码。

### 5.3 新建和编辑数据源

用户填写：

- 数据源名称。
- 数据库类型。
- 主机、端口、数据库名和 schema（按连接类型显示）。
- 用户名和密码。
- 可选连接参数及连接备注。

保存前可执行连接测试。连接测试成功后，用户可保存数据源；连接测试失败时，显示连接失败原因并允许修改配置重试。编辑连接时，如果密码留空则保留原凭据；明确输入新密码时替换旧凭据。

同一工作区内数据源名称不可重复。删除数据源前，平台检查其是否被数据集、同步任务或其他资源引用；存在引用时列出关联资源，并要求用户先解除引用或明确执行级联处理。

### 5.4 数据源目录浏览

用户展开数据源后可浏览数据库、schema 和表。选择数据表后展示字段名称、字段类型、是否可空、主键信息及字段备注（源数据库提供时）。目录支持按名称搜索表和字段。

目录浏览用于发现和选择数据，不直接修改外部数据库表结构。

### 5.5 连接状态

用户可手动测试单个数据源，也可从列表查看最近一次连接结果。连接失败时展示失败时间、可识别的原因和修复提示，例如地址不可达、认证失败、数据库不存在或权限不足。

## 6. 数据管理

### 6.1 数据目录

数据管理页面以数据源为入口展示工作区可访问的库、schema、表和字段；同时提供平台数据集列表。用户可以查看对象来源、字段结构、数据量信息和数据预览。

平台数据集与外部数据库中的源表采用不同标识展示。外部源表的结构信息来自数据源目录；平台数据集由工作区管理，并可作为 SQL、API、同步、图表和工作流的数据对象。

### 6.2 文件上传

用户可选择 CSV 或 Excel 文件上传。上传后进入导入向导，系统解析表头、字段类型、总行数和部分样例数据。用户可以：

- 修改数据集名称。
- 修改字段名称和字段类型。
- 选择日期格式、空值处理和字段转换规则。
- 预览解析后的数据。
- 选择写入平台数据区的新表，或追加到结构兼容的已有表。
- 确认导入，或返回修改导入设置。

导入向导需显示文件名、文件大小、识别出的字段、样例数据和导入目标。字段名称重复、字段名为空、数据格式无法解析或目标表结构不匹配时，指出问题字段并允许用户修正或取消。

### 6.3 数据集列表与详情

数据集列表展示名称、所属 schema/表名、数据来源、字段数、行数、创建者和更新时间。用户可按名称、来源和创建时间搜索或筛选。

数据集详情包括：

- 基本信息：名称、描述、物理表名、来源文件或来源任务、创建时间和更新时间。
- 字段信息：字段名称、数据类型、字段说明、是否为空及主键标识。
- 数据预览：分页查看样例数据，支持列排序和文本搜索。
- 使用情况：关联的 API、同步任务、工作流、图表和 Python 模型。
- 操作：修改名称和描述、维护字段说明、查看数据、删除数据集。

### 6.4 数据集删除

删除数据集时展示引用它的 API、同步任务、工作流、图表和模型。用户解除引用或确认影响后才能删除。删除操作同时移除数据集元信息和其平台数据表。外部数据库中的源表不属于平台数据集删除范围。

### 6.5 数据集使用

数据集可被 SQL 分析、数据 API、数据同步目标端、工作流、可视化分析和 Python SDK 引用。资源选择器支持按名称搜索，并显示数据集的字段、数据来源和最近更新时间，帮助用户确认选择对象。

## 7. SQL 分析

### 7.1 SQL 工作台布局

SQL 工作台由脚本导航区、编辑区、数据源选择区和结果区组成。

- 脚本区展示用户可访问的工作区脚本，支持搜索、新建、重命名、复制和删除。
- 编辑区提供 SQL 编辑、语法高亮、格式化和常用快捷键。
- 数据源选择区展示当前可访问的数据源及其连接状态。
- 结果区展示查询结果、执行状态、耗时、行数、影响行数和错误信息。

### 7.2 编写和运行 SQL

用户选择数据源后编写 SQL 并运行。运行前可以清空编辑区、格式化 SQL 或保存脚本。执行中显示运行状态，用户可取消当前查询；执行完成后显示结果或业务错误。

平台内置数据源支持查询和经授权的数据变更语句；外部数据源以只读查询为主。用户可在当前工作区权限范围内查看表结构并编写对应方言 SQL。

### 7.3 查询结果

查询结果以表格显示，支持列宽调整、排序和查看单元格内容。长文本和空值采用明确的视觉呈现。结果达到显示上限时提示用户结果已截断，并提供调整查询或追加筛选条件的建议。

用户可将查询结果导出为 CSV。导出内容与当前查询结果一致，列顺序与结果区一致。

### 7.4 SQL 脚本管理

脚本具有名称、SQL 内容、描述、创建者、创建时间和最近更新时间。用户可以创建、打开、修改、复制、重命名和删除脚本。切换或关闭存在未保存修改的脚本时，系统提示保存、放弃或取消切换。

脚本为工作区共享资源。脚本本身保存 SQL 内容，不自动保存上次执行结果；用户运行脚本后可在当前页面查看本次结果。

### 7.5 查询历史

查询历史记录脚本或 SQL 摘要、数据源、发起人、执行时间、运行时长、状态和错误摘要。用户可从历史记录重新打开 SQL 并再次运行。凭据和敏感参数不显示在历史详情中。

### 7.6 SQL 参数

支持在脚本中声明具名参数。运行前系统识别参数并显示参数表单；用户填写值后执行查询。参数可设置名称、说明、类型、默认值和是否必填。参数值以绑定参数传递，不拼接为 SQL 文本。

## 8. 数据同步

### 8.1 同步任务列表

任务列表展示任务名称、源数据源、目标数据源、源对象、目标表、同步方式、调度状态、最近运行状态、最近开始时间和下一次运行时间。用户可新建、编辑、复制、运行、暂停调度、查看详情和删除任务。

### 8.2 同步任务配置

配置向导包括以下步骤：

1. **基本信息**：任务名称、任务描述。
2. **选择数据源**：选择源数据源和目标数据源。
3. **选择读取对象**：选择源表，或填写只读 SELECT 查询；查询可配置具名参数。
4. **选择写入目标**：选择目标 schema 和表；可使用已有表或创建新表。
5. **字段映射**：将源字段映射到目标字段，配置字段类型转换、常量值、默认值和字段忽略规则。
6. **写入规则**：选择覆盖、追加或按主键更新/插入；配置冲突键及目标表创建策略。
7. **运行设置**：配置超时、失败重试次数、并发行为和运行计划。
8. **预览与保存**：查看源/目标摘要、字段映射和写入方式，执行连接及字段校验后保存。

源端和目标端不能指向同一张表。源查询只允许读取数据。选择按主键更新/插入时，必须配置目标端存在的冲突键。

### 8.3 同步方式

- **覆盖目标表**：运行前清理目标表中的既有数据，再写入本次读取结果。
- **追加数据**：保留目标表现有数据，将本次读取结果追加到表尾。
- **按键更新/插入**：依据用户选择的一个或多个冲突键更新已存在记录，插入新记录。
- **全量读取**：读取源表或查询的全部结果。
- **条件读取**：通过源查询条件和参数限定读取范围，可在计划运行时设置参数值。

任务执行采用批次语义。每次运行独立形成一个任务实例；不包含基于日志位点的实时 CDC 同步。

### 8.4 字段映射与预览

字段映射页面并排展示源字段和目标字段。系统按字段名提供自动匹配，用户可手动调整映射。类型不兼容、必填字段未映射、冲突键缺失或目标字段不存在时，禁止保存或运行并定位错误项。

用户可预览样例数据经过字段映射和转换后的目标形态。敏感字段可配置为忽略或使用固定替代值。

### 8.5 同步运行记录

同步详情展示运行实例列表。每个实例记录触发来源、开始和结束时间、当前阶段、状态、读取行数、写入行数、失败行数、重试次数和错误摘要。

实例详情按阶段显示连接、读取、转换和写入结果。运行失败时保留错误摘要和可重新运行入口；重新运行创建新实例，不覆盖历史实例记录。用户可取消运行中的任务；若当前阶段无法安全取消，则显示取消请求状态并在阶段结束时停止后续处理。

### 8.6 同步调度

用户可配置一次性运行或周期计划。周期计划支持开始时间、频率、间隔、运行时段和结束条件。调度详情展示下一次执行时间、最近执行结果及暂停状态。

同一任务已有运行实例时，调度触发按任务的并发策略处理：跳过本次触发、等待前次结束或允许并行。默认采用不重叠执行，用户可在任务配置中调整。

## 9. 工作流编排

### 9.1 工作流列表

工作流列表展示名称、描述、创建者、调度状态、最近运行结果、最近运行时间和下次运行时间。用户可新建、编辑、复制、手动运行、暂停调度、查看运行历史和删除工作流。

### 9.2 流程编辑器

流程编辑器由节点面板、画布、属性面板和校验/运行工具栏组成。用户将节点拖入画布并通过连线定义依赖关系。

支持的节点包括：

- **SQL 节点**：选择数据源、编写或选择 SQL 脚本、配置参数。
- **数据同步节点**：选择已有同步任务，或配置本流程专用的同步参数。
- **Python 节点**：选择已注册的 Python 模型或脚本并填写运行参数。
- **通知节点**：配置通知渠道、接收对象、通知内容和触发条件。

节点可设置名称、描述、失败重试次数和超时策略。画布展示节点依赖、节点运行状态和错误状态。

### 9.3 流程校验与保存

保存或运行前，系统检查节点配置完整性、节点依赖关系、数据资源归属和循环依赖。校验失败时定位到相应节点或连线。

用户可保存草稿并继续编辑。每次启动流程时，系统记录当次流程定义快照；后续编辑流程不改变已启动实例的执行定义。

### 9.4 流程运行

流程实例按依赖关系执行。没有上游依赖的节点可先运行；节点成功后，其下游节点进入可运行状态；节点失败后，依赖该节点的下游节点不再执行。互不依赖的分支可并行运行。

实例状态包括等待、运行中、成功、失败、取消中和已取消。实例详情显示流程图、各节点状态、输入参数、运行时间、重试次数、输出摘要和错误信息。用户可重试失败节点及其下游，或从头启动新实例。

### 9.5 流程调度

用户可设置手动运行或周期运行计划。流程调度规则支持启用、暂停、恢复和修改。修改计划仅影响之后触发的实例；已启动实例按启动时保存的流程定义和参数运行。

### 9.6 流程通知

通知节点可由上游成功、失败或无论结果触发。用户选择已配置通知渠道和接收对象，并使用流程变量组织通知内容。通知发送失败记录在节点运行详情中，可按节点重试策略重新发送。

## 10. 数据服务与 API 发布

### 10.1 API 目录

API 列表展示名称、访问路径、数据对象、API 类型、状态、授权应用数、创建者和更新时间。用户可搜索、筛选、查看详情、编辑、停用、启用和删除 API。

API 类型包括：

- **数据集 API**：读取平台数据集中的记录。
- **Python 模型 API**：调用已发布的 Python 模型并返回模型执行结果。

### 10.2 数据集 API 配置

创建数据集 API 时，用户选择数据集并配置：

- API 名称、描述和唯一访问路径。
- 对外暴露的字段及字段顺序。
- 可用于过滤的字段及过滤方式。
- 可用于排序的字段。
- 分页默认值和单次返回上限。
- API 启用状态。

API 只返回显式选择的字段。过滤和排序字段必须属于允许字段。API 不允许配置任意 SQL。

### 10.3 API 测试与说明

API 详情展示调用地址、请求方法、认证方式、参数列表、字段定义、示例请求和示例响应。用户可在详情页填写过滤和分页参数执行在线测试。测试结果展示状态码、响应数据和错误信息。

### 10.4 调用应用

应用列表展示应用名称、AppKey、Secret 脱敏值、创建时间、关联 API 数量和状态。用户可创建应用、修改名称、查看 Secret、复制凭证、停用或删除应用。

创建应用时生成 AppKey 和 AppSecret。创建成功时向用户展示完整 Secret 并提示保存。用户可通过明确操作再次查看 Secret；查看和复制均须由用户主动触发。停用应用后，应用无法调用 API；删除应用时移除其全部 API 授权。

### 10.5 API 授权

用户在 API 详情中查看已授权应用并调整授权关系。一个 API 可以授权多个应用，一个应用可以获得多个 API 的访问权限。未授权应用不能调用该 API。移除授权后，后续请求立即失去该 API 的访问权限。

### 10.6 数据集 API 调用

外部系统通过 GET 请求调用已发布的数据集 API，并在请求头提供 AppKey/AppSecret。请求可携带 API 配置中允许的过滤参数、排序字段和分页参数。

响应包含字段定义、数据行、总记录数、当前页和页大小。无效凭证、无效参数、未授权访问、已停用 API 和查询错误分别返回明确的错误信息。未授权访问不泄露 API 是否存在或其所属数据内容。

### 10.7 API 调用记录

调用记录展示 API、调用应用、调用时间、请求结果、响应耗时、返回行数和错误类型。用户可按 API、应用、时间范围和调用结果筛选，并查看单次调用详情。凭证值和敏感参数不在记录中明文展示。

### 10.8 Python 模型 API

用户从已注册模型创建服务 API，配置服务名称、访问路径、输入参数、返回结构和调用应用授权。模型服务请求需校验参数定义和应用授权。模型执行状态、运行时间和错误摘要可在 API 运行记录中查看。

## 11. 可视化分析

### 11.1 图表列表

图表列表展示名称、数据集、图表类型、创建者和更新时间。用户可新建图表、复制、编辑、预览、删除，并可将图表加入一个或多个仪表盘。

### 11.2 图表制作

图表编辑器包括数据选择、字段配置、筛选排序、图表样式和预览区域。用户选择数据集后，将字段拖放或选择到分析槽位：

- **维度**：分类、日期或地理位置字段。
- **度量**：数值字段及聚合方式，例如求和、平均值、计数、去重计数、最大值和最小值。
- **筛选**：字段、操作符和值；支持多个条件组合。
- **排序**：按维度或度量升序/降序排列。
- **限制**：设置展示记录数或 Top N。

支持的图表类型包括柱状图、折线图、饼图、明细表和指标卡。不同图表类型显示对应的字段配置，并在字段缺失或类型不兼容时说明需要调整的字段。

用户可配置图表标题、图例、坐标轴、数据标签、数值格式、颜色和空值显示方式。预览区域随配置变化更新；用户可保存草稿或保存为可复用图表。

### 11.3 图表筛选与交互

图表可配置默认筛选条件和可见筛选器。查看者修改筛选条件后，图表按当前条件重新查询数据。仪表盘可向多个图表下发公共筛选条件。

图表之间可配置联动：用户点击一个图表中的维度值时，其他关联图表按该值过滤。支持为维度配置下钻字段层级；查看者可从汇总层级进入更细粒度数据，并返回上一级。

地图和自定义主题可作为图表类型与外观配置扩展；图表分析模型保持维度、度量、筛选和排序等统一语义。

### 11.4 仪表盘管理

仪表盘列表展示名称、描述、创建者和更新时间。用户可以新建、复制、编辑、预览和删除仪表盘。

仪表盘编辑器支持：

- 从工作区图表库添加或移除图表。
- 调整图表卡片位置、宽度和高度。
- 配置仪表盘标题、描述、布局和默认筛选条件。
- 配置图表间联动关系和联动字段。
- 设置默认时间范围或其他公共筛选条件。
- 预览不同屏幕宽度下的展示布局。

仪表盘查看者可以调整可见筛选器、查看图表数据和恢复默认筛选。编辑者保存的布局作为仪表盘默认展示状态。

### 11.5 图表和仪表盘分享

工作区成员可查看工作区共享的图表和仪表盘。需要向工作区外部分享时，通过平台的数据服务配置受控的 API 或分享入口，并设置访问授权；不通过公开 URL 默认暴露工作区数据。

## 12. Python 开发

### 12.1 Python 工作区

Python 工作区提供 Notebook、脚本模型和运行历史的统一入口。用户可查看自己和工作区共享的 Python 资源，并从工作区数据集、数据源和已发布 API 中选择数据输入。

### 12.2 Notebook

Notebook 由多个代码单元和 Markdown 单元组成。用户可新建、命名、保存、复制、重命名和删除 Notebook；逐单元运行或运行全部单元；停止当前运行；查看文本、表格、图形和错误输出。

Notebook 支持选择 Python 运行环境、查看当前运行状态、安装已允许的依赖和保存执行结果。用户可通过平台 Python SDK 读取数据集、写回数据集和调用已授权 API。

Notebook 仅供交互式数据探索。用户确认结果可复用后，可将代码整理成参数化模型脚本。

### 12.3 程序模型

用户可创建模型并维护名称、描述、代码、运行入口、参数定义、输入数据、输出数据和共享范围。参数定义包括参数名、类型、说明、默认值、是否必填和可选范围。

模型支持在线编辑、保存、参数校验、试运行、查看运行输出和发布版本。试运行前用户填写参数并选择输入数据；运行完成后查看日志、结果摘要和生成的数据集。

模型可设为仅自己可见或工作区共享。工作区共享模型可被其他成员运行，但模型源代码的可见性由模型所有者设置。

### 12.4 模型共享库

共享库提供三个视图：

- **工作区共享**：成员共享且允许当前用户使用的模型。
- **我的模型**：当前用户创建或维护的模型。
- **定时运行**：当前用户可管理的模型计划任务。

用户可以按名称、创建者、标签和更新时间搜索模型，查看说明、参数、输入输出和运行记录。模型共享范围不跨工作区，不提供跨租户交易或购买流程。

### 12.5 Python 运行记录

运行记录展示模型/Notebook、发起人、触发方式、开始结束时间、运行状态、资源使用摘要、输出数据集和错误信息。用户可打开日志、复制参数并重新运行。重新运行创建新的运行记录，不覆盖原记录。

### 12.6 Python SDK 与数据读写

Python SDK 提供以下业务操作：

- 按数据集 ID 或名称读取数据并返回 DataFrame。
- 将 DataFrame 写入新数据集，或追加/覆盖已有数据集。
- 调用工作区内已授权的数据 API。
- 获取当前任务允许访问的数据资源和参数。

读写操作遵守当前用户和工作区授权。SDK 不向用户脚本暴露平台数据库连接凭据。写回数据集时，用户选择数据集名称、字段类型和写入方式；完成后返回数据集标识和写入结果。

### 12.7 Python 模型服务化

模型所有者可将已验证的模型发布为 REST 服务。发布配置包括访问路径、输入参数、返回内容、调用应用授权和服务状态。调用方通过应用凭证提交参数并取得执行结果或任务标识。

服务详情展示运行状态、调用记录、最近错误和模型版本。模型停用后不再接受新请求；正在执行的请求按当前运行策略完成或停止。

### 12.8 Python 资源配额

工作区管理员可设置租户可同时运行的容器数、单个运行实例 CPU 和内存上限。超出并发配额的任务进入队列，并向用户显示排队位置或资源不足原因。管理员可查看当前运行实例和租户配额使用情况。

### 13.1 通知中心

通知中心展示与当前用户相关的任务完成、任务失败、成员管理和资源授权消息。用户可查看未读消息、标记已读和按类别筛选。

### 13.2 任务通知偏好

用户可选择是否接收数据同步、工作流、Notebook 和模型运行结果通知，并配置可用的站内、邮件或 Webhook 渠道。通知消息包含任务名称、运行状态、结束时间和详情链接，不包含数据库密码、AppSecret 或完整敏感数据。

## 14. 核心业务流程

### 14.1 团队接入并分析数据

创建工作区 → 管理员邀请或创建成员 → 添加外部数据源或上传文件 → 浏览数据结构和样例 → 创建数据集 → SQL 查询与保存脚本 → 将结果用于图表、同步或 API。

### 14.2 数据源接入流程

新建数据源 → 填写连接信息 → 测试连接 → 保存 → 浏览库表和字段 → 在 SQL、同步任务或数据目录中选择该数据源。

### 14.3 文件导入流程

选择文件 → 系统解析表头和类型 → 用户检查样例并修正字段 → 选择新建表或追加目标 → 查看导入摘要 → 确认导入 → 查看新数据集及导入结果。

### 14.4 SQL 分析流程

选择数据源 → 新建或打开脚本 → 编写 SQL 和参数 → 运行并查看结果 → 根据结果修改筛选/聚合 → 保存脚本 → 导出 CSV 或将数据对象用于其他模块。

### 14.5 数据同步流程

创建任务 → 配置源和目标 → 选择表或查询 → 配置字段映射 → 选择写入方式 → 预览和校验 → 保存并试运行 → 查看运行记录 → 设置周期计划。

### 14.6 工作流流程

创建流程 → 添加 SQL、同步、Python 和通知节点 → 连接依赖 → 配置节点参数及失败处理 → 校验流程 → 保存 → 手动运行或设置计划 → 查看实例和节点结果 → 按需重试失败节点。

### 14.7 发布数据 API 流程

选择数据集 → 配置 API 路径和字段 → 设置过滤、排序和分页 → 在线测试 → 创建调用应用 → 为应用授权 API → 查看调用说明 → 外部系统调用 → 在调用记录查看请求情况。

### 14.8 制作仪表盘流程

选择数据集制作图表 → 配置维度、度量和筛选 → 预览并保存图表 → 新建仪表盘 → 添加图表并布局 → 配置公共筛选和图表联动 → 保存并供工作区成员查看。

### 14.9 Python 模型生产流程

在 Notebook 探索数据 → 整理代码为参数化模型 → 配置输入和输出 → 试运行并检查结果 → 写回平台数据集 → 分享给工作区成员 → 作为工作流节点或 Python 模型 API 使用。

## 16. 业务规则汇总

1. 工作区是数据、资源和成员的隔离边界。工作区成员只能访问其所属工作区资源。
2. 工作区内资源默认共享；管理员和成员按角色拥有不同的成员管理权限。
3. 外部数据源在 SQL 分析中按只读方式使用；目标端写入通过数据同步任务中明确配置的操作完成。
4. 文件导入的数据进入平台数据区，成为可由 SQL、API、工作流、图表和 Python 复用的数据集。
5. 数据集删除前检查所有下游引用，必须让用户明确处理关联资源。
6. 数据同步任务一次运行对应一个独立实例，历史实例保留可查看；覆盖、追加和按键更新/插入的语义在任务配置中明确展示。
7. 工作流按节点依赖执行；上游失败时，依赖该节点的下游不执行；每次运行使用启动时保存的流程定义。
8. API 只允许访问显式配置并授权的数据对象。列、过滤参数和排序字段均受 API 发布配置控制。
9. 外部应用凭证与平台用户账号分离；应用只能调用被授权且启用的 API。
10. 图表和仪表盘引用工作区数据集；筛选、联动和下钻在图表或仪表盘配置中定义。
11. Python 脚本通过平台 SDK 访问数据；Python 运行结果可回写为数据集，并可供 SQL、API、可视化和工作流使用。
12. 任务、流程和模型的运行结果以独立运行记录保存，重新运行不覆盖历史记录。
