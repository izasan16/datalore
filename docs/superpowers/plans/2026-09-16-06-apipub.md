# 子计划 6：API 发布（数据服务）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把「数据集（表）」一键发布成只读 REST API；租户可创建「应用」（appKey/appSecret），对 API 授权；外部系统携凭证调用 `GET /api/open/{path}` 取数。前端启用侧边栏「API 发布」，全部表单走独立页面（不用弹窗）。

**Architecture（MVP 取舍）：**
- 数据形态：**只支持基于 dataset（表）的等值过滤查询**，不支持自定义 SQL 发布（后续迭代）；返回 JSON `{columns, rows, total, page, size}`。
- 鉴权：请求头 `X-Api-Key` + `X-Api-Secret`（HTTPS 下明文头，MVP 够用；HMAC 签名列为后续项）。应用密钥 AES-GCM 加密存储，管理页可解密查看（与数据源密码同一套 `AesGcmCipher`）。
- 路由解析：`api_pub.path` **全局唯一**（所有租户共用一个命名空间，冲突即 400），这样 `/api/open/{path}` 无需登录态即可定位租户。
- 隔离校验：应用 → API 必须存在同租户 grant 记录；API 停用时调用返回 404。
- SQL 组装：列名/表名只来自发布配置（标识符双引号转义），过滤值一律走 `PreparedStatement` 占位符；`order_by` 必须在暴露列内；`size ≤ max_rows`。不存在注入面。
- 免会话端点：`/api/open/**` 在 `WebConfig` 中排除 `AuthInterceptor`，自行按头鉴权，不经 Sa-Token。

**数据模型（V9）：**

```sql
api_pub   (id, tenant_id, name, path UNIQUE, dataset_id, columns TEXT(JSON数组，暴露列),
           filter_columns TEXT(JSON数组，允许等值过滤的列子集), max_rows INT default 1000,
           status SMALLINT default 1, created_at, updated_at)
api_app   (id, tenant_id, name, app_key UNIQUE, app_secret_enc, created_at)
api_grant (id, tenant_id, app_id, api_id, created_at, UNIQUE(app_id, api_id))
```

app_key 生成 `"ak_" + 16位随机`，secret `"sk_" + 32位随机`（SecureRandom, base36/base62 均可）。

### Task 2: ApiAppService（应用管理）+ ApiPubService（发布/授权）

**Files:**
- Create: `server/src/main/java/com/daaspro/apipub/ApiAppService.java`
- Create: `server/src/main/java/com/daaspro/apipub/ApiPubService.java`
- Create: `server/src/main/java/com/daaspro/apipub/ApiPubController.java`（管理端 `/api/apipubs`、`/api/apiapps`）

ApiAppService：`create(name)`（生成 key/secret、secret AES 加密入库、返回明文一次）、`list()`（secret 脱敏 `sk_ab****...`）、`rename/delete`（delete 级联删 grant）。
ApiPubService：`create(datasetId, name, path, columns, filterColumns, maxRows)`（dataset 属于本租户；path 正则 `^[a-z0-9][a-z0-9-_]{1,63}$`；columns ⊆ dataset 列；filterColumns ⊆ columns；path 全局唯一）、`update`（可改 name/columns/filter/maxRows/status）、`delete`（级联删 grant）、`grants(apiId)`、`setGrants(apiId, appIds)`（校验 app 同租户）。

管理端点：
```
GET/POST /api/apiapps  PUT/DELETE /api/apiapps/{id}   （POST 返回明文 secret 仅此一次响应）
GET/POST /api/apipubs  GET/PUT/DELETE /api/apipubs/{id}
PUT /api/apipubs/{id}/grants   body: {appIds:[...]}
GET /api/apipubs/{id}/grants
```

`GET /api/open/{path}`：
1. 头缺失/密钥不符（AES 解密后 constant-time 比较）→ 401；path 不存在或 status=0 或 grant 缺失 → 404。
2. 查询参数：`page`（默认 1，≥1）、`size`（默认 ≤ max_rows）、`order_by`+`order`(asc/desc)、其余参数名必须在 filter_columns 内（等值），未知参数 → 400。
3. 组装：`SELECT <暴露列> FROM "<table>" [WHERE 等值 AND...] [ORDER BY] LIMIT ? OFFSET ?`，另发 `SELECT count(*)` 同 WHERE；表名取 dataset.tableName（内置源租户 schema 连接，复用 `ConnectionManager.builtinPool`）。
4. 返回 `{columns, rows, total, page, size}`；错误统一 JSON `{message}`。

### Task 4: 集成测试（TDD 收尾）

**Files:**
- Create: `server/src/test/java/com/daaspro/apipub/ApiPubFlowTest.java`

用例（复用现有注册租户 + 上传数据集流程建数据）：
1. 发布 API（暴露全部列、name 列可过滤）→ 建应用 → 授权 → open 调用返回行数据、total 正确。
2. 未授权应用调用 → 404；错密钥 → 401；未知参数 → 400；等值过滤命中。
3. path 冲突（跨租户）→ 400；API 停用 → 404。
4. size 超过 max_rows → 截断到 max_rows；`order_by` 非暴露列 → 400。
5. 管理端跨租户访问他人 API → 404（tenant-scoped getOwned 模式）。
