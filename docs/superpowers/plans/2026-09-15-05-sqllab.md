# 子计划 5：SQL 分析（SQL Lab）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** SQL 编辑器（Monaco，本地打包离线可用）+ SQL 网关（租户 schema 限定、单语句、语句/黑名单防护、超时与行数上限）+ 结果网格 + CSV 导出 + 脚本管理（CRUD）。前端启用侧边栏「SQL 分析」。

**Architecture:** `POST /api/sql/run` 执行单条 SQL：内置源在租户 schema 上读写（DDL/DML/SELECT 均可，但黑名单拦 `pg_*`、`public.`、`information_schema.`、其它 `tenant_*` schema 引用、`COPY/GROUP/GRANT/SET/ALTER SYSTEM` 等）；外部源仅允许 SELECT（跨租户隔离的 MVP 方案，见「安全模型」）。`sql_script` 表存租户脚本。结果上限 maxRows（默认 10000，属性可配）、语句超时 maxSeconds（默认 30）。

**安全模型（MVP 取舍，必须写进代码注释与 README）**：
1. 所有校验基于 **normalize 后的 SQL**：剥注释（-- 与 /* */）、字符串字面量（含 PG 单引号 '' 转义与 $$ 美元引用）替换为占位符——黑名单不会被字符串内容误触发，也不可用注释/字符串绕过（占位符仍保留语句结构）。
2. 多语句拒绝（normalize 后按分号切分 >1 即拒）。
3. 语句首关键字白名单：内置源 SELECT/WITH/INSERT/UPDATE/DELETE/CREATE/ALTER/DROP/TRUNCATE；外部源仅 SELECT/WITH。
4. 模式黑名单（对 normalize 文本，忽略大小写）：`pg_`（函数与目录）、`\bpublic\s*\.`、`information_schema\s*\.`、`tenant_[a-z0-9_]+`（必须等于自身 schema）、`\bgrant\b|\brevoke\b|\bset\s+role\b|\bsession_authorization\b|\bcopy\b|\bvacuum\b|\banalyze\b(?!.)` 等。已知残余风险：非常见 schema 全限定名仍可探测——列为后续用「每租户只读角色 + grants」强隔离的迭代项。
5. 连接侧：`setQueryTimeout(maxSeconds)` + `setMaxRows(maxRows+1)`（多取 1 行判定 truncated）。

**Tech Stack:** 后端零新依赖（JDBC 原生）；前端 `monaco-editor` + `@monaco-editor/react`（loader.config 用本地包，离线可用）。

### Task 1: SQL 语句扫描器（纯单测 TDD）

**Files:**
- Create: `server/src/main/java/com/daaspro/sqllab/SqlScanner.java`
- Test: `server/src/test/java/com/daaspro/sqllab/SqlScannerTest.java`

核心 API：

```java
public final class SqlScanner {
    public record Normalized(String sql) {}
    /** 剥注释与字符串字面量；字符串替换为 '' 占位。 */
    public static String normalize(String sql);
    /** 返回首关键字（大写）。normalize 后取第一个词。 */
    public static String firstKeyword(String normalized);
    /** 分号数量（normalize 后）。 */
    public static int semicolons(String normalized);
    /** 找到所有 tenant_xxx 引用（normalize 后）。 */
    public static java.util.Set<String> tenantRefs(String normalized);
}
```

测试用例（全绿为准）：
- `-- comment; DROP` 与 `/* ; */` 剥除；`'a;b'`、`'it''s'`、`$$x;y$$` 字符串归一化后不含分号。
- `firstKeyword("  with t as (select 1) select * from t") == "WITH"`。
- `semicolons("select 1; select 2") == 1`（尾部分号不计：`select 1;` == 0，见实现）。
- `tenantRefs("select * from tenant_a.t cross join public.b")` 含 `tenant_a`。

校验流水线（`run(sql, datasourceId)`）：normalize → 分号/多语句拒 → 首关键字白名单 → 黑名单模式（tenantRefs 须等于当前 schema）→ 选池（builtin → `builtinPool(ds.id, tenant schema)`；external → `pool(ds, pwd)`）→ 执行。返回 `QueryResult(columns, rows, truncated, rowCount, elapsedMs, kind, affectedRows)`。

测试（HTTP/服务层，注册真实租户跑内置源）：
1. `CREATE TABLE demo(a int)` → `INSERT` → `SELECT` → 结果正确。
2. `select 1; select 2` 拒（多语句）。
3. `DROP TABLE public.tenant` 拒；`select * from information_schema.tables` 拒；`select pg_sleep(0.1)` 拒。
4. `select 'tenant_9999'` **放行**（字符串归一化防误杀）。
5. `select '--fake' ; --` 结构判断不受注释影响。
6. 跨租户：租户 A `select * from tenant_B.x` 被拒（tenantRefs ≠ 自身）。
7. 行数上限：属性覆盖 `maxRows=5`，`select generate_series(1,10)` → 返回 5 行 + truncated=true。
8. 外部源仅 SELECT：注册平台 PG 为外部源，`select count(*) from tenant` 成功；`create table` 拒。
9. 超时：属性覆盖 `maxSeconds=1`，`select sum(g) from generate_series(1,300000000) g` → 报错含 timeout。
